💾 Backup Data

Export seluruh data koperasi ke file Excel. Simpan file ini di tempat aman sebagai cadangan.

Yang akan dibackup:
✅ Data anggota
✅ Riwayat simpanan
✅ Data pinjaman
✅ Riwayat cicilan
✅ Data event
✅ Poin reward
✅ Pengeluaran kas
✅ Denda keterlambatan
✅ Pengaturan (rujukan)
Info backup:
📅 Tanggal: -
📊 Format: Excel (.xlsx)
🔒 Data: Lengkap & aman
⏱️ Waktu: ~5-10 detik
📥 Restore Data
⚠️ Perhatian: Restore memulihkan Pinjaman, Simpanan, Event, Cicilan, Pengeluaran Kas, dan Poin. Baris yang sudah ada tidak ditimpa — hanya yang belum ada yang ditambahkan, jadi aman dijalankan berulang.

Akun anggota tidak bisa dibuat ulang dari berkas backup, karena identitasnya tersimpan di sistem login, bukan di tabel biasa. Kalau seluruh data hilang, buat dulu akun anggotanya lewat menu Anggota, baru jalankan restore.

Sheet Pengaturan (bunga, plafon, denda) sengaja tidak dipulihkan otomatis — isi ulang lewat menu Pengaturan sesudah restore.
